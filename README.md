# Калуга — доска объявлений

Пошаговая инструкция, как из этих файлов сделать настоящий работающий сайт в интернете.
Не торопись — просто иди по шагам по порядку.

## Шаг 1. Создать бесплатную базу данных (Firebase)

1. Зайди на https://console.firebase.google.com и войди через Google-аккаунт
2. Нажми "Add project" / "Создать проект", назови как хочешь (например, kaluga-board)
3. На экране проекта нажми иконку "</>" (Web) — это добавит веб-приложение
4. Дай приложению имя, нажми "Register app"
5. Firebase покажет объект `firebaseConfig` с кучей значений (apiKey, authDomain и т.д.) —
   скопируй их в файл `src/firebase.js` вместо "ВСТАВЬ_СЮДА"
6. В левом меню найди "Firestore Database" → "Create database" → выбери "Start in test mode"
   (это временный режим, безопасность настроим позже, когда сайт заработает)

## Шаг 2. Установить нужные программы на компьютер

1. Скачай и установи Node.js: https://nodejs.org (кнопка LTS)
2. Установи Git: https://git-scm.com/downloads

## Шаг 3. Запустить сайт у себя на компьютере (проверка)

Открой терминал/командную строку в папке проекта и выполни по очереди:

```
npm install
npm run dev
```

Откроется адрес вроде `http://localhost:5173` — открой его в браузере и проверь,
что доска работает и объявления сохраняются.

## Шаг 4. Выложить код на GitHub

1. Зарегистрируйся на https://github.com (бесплатно)
2. Создай новый репозиторий (New repository), назови kaluga-board
3. Следуй инструкциям GitHub "…or push an existing repository from the command line"
   (это несколько команд git, которые нужно скопировать и выполнить в терминале)

## Шаг 5. Опубликовать сайт (Vercel)

1. Зайди на https://vercel.com, зарегистрируйся через GitHub-аккаунт
2. Нажми "Add New" → "Project", выбери свой репозиторий kaluga-board
3. Vercel сам определит, что это Vite-проект — просто нажми "Deploy"
4. Через минуту получишь ссылку вида kaluga-board.vercel.app — сайт уже в интернете

## Шаг 6. Подключить свой домен

1. Купи домен (например, на reg.ru) — что-то вроде kaluga-obyavleniya.ru
2. В настройках проекта на Vercel открой "Settings" → "Domains", добавь свой домен
3. Vercel покажет, какие DNS-записи нужно указать у регистратора (reg.ru) —
   зайди в панель управления доменом на reg.ru и впиши эти записи
4. Подождать может понадобиться от 10 минут до пары часов, пока домен заработает

## Если что-то не получается

На любом шаге просто вернись в чат с Claude и опиши, на чём застрял (можно
прислать текст ошибки) — вместе разберёмся.
